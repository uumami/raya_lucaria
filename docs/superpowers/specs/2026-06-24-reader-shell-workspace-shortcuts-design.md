# Reader Shell Workspace Shortcuts Design

## Goal

Bring the old branch's useful course-app navigation feel into the current static reader shell by adding local workspace shortcuts to the course map and tightening learning-rail landmark markup.

## Context

The current branch already has the major graph and shell fusion pieces: a sticky command bar, a left course map, a main article, a right learning rail, local Search/Graph/Practice/Tasks workspaces, collapsible graph panels, graph focus modes, local comfort controls, and no browser-side MathJax or external renderer dependencies.

The old `main` branch still has one useful reader affordance that is not fully represented in normal article pages: the left navigation starts with course-level destinations such as tasks and graph before the content tree. That makes the shell feel like a course workspace instead of only a document outline.

## Design

Add a compact `Course workspaces` section at the top of the generated course map on normal reader pages. It contains static links to:

- Search, focused by the current page title;
- Graph, focused by the current page stable page ID;
- Official Practice;
- Official Tasks.

These are the same generated static workspaces already available in the top command bar. The left-map shortcuts make those destinations discoverable for desktop readers who live in the course map, while the top command bar remains the fast global tool strip.

The shortcuts are normal anchors, not buttons. They use deployment-neutral relative URLs generated by the builder and no runtime fetch, storage, tracking, ranking, progress, or recommendation language. They are hidden in the compact collapsed map rail so the collapsed rail stays narrow and page-navigation focused.

The learning rail opening tag should also be corrected so it emits one valid `aria-label="Learning context"` and one `data-raya-learning-rail="expanded"` attribute, with no stray duplicated text in the document.

## Scope

This loop changes:

- `packages/static/src/raya_static/builder.py` to pass workspace hrefs into the course map, render the shortcut section, and fix the learning rail tag;
- `packages/static/src/raya_static/rendering.py` to style and hide the shortcut section in compact map mode;
- `tests/contracts/test_static_builder.py` and `tests/e2e/test_preview_static_read_path.py` to prove the static links, collapsed behavior, and landmark markup;
- `docs/foundation/20_learning_renderer_contract.md` and role docs only if needed to clarify visible reader behavior.

This loop does not change the source course contract, artifact data shape, graph/search/practice/tasks payloads, scoring, submissions, personal state, recommendations, or external assets.

## Test Strategy

Add tests before implementation for:

- reader HTML contains one course-map workspace section with four static links;
- search and graph shortcut URLs are page-aware;
- practice and tasks shortcut URLs are static local workspace paths;
- learning rail markup does not contain duplicated stray `aria-label` text;
- desktop browser layout shows the workspace shortcuts in the expanded map;
- collapsed map hides the workspace shortcut section and keeps compact page links operable;
- no horizontal overflow after the new section appears.
