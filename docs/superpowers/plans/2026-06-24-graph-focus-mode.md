# Graph Focus Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the static graph `Expand graph` control a real desktop focus mode with both side panels collapsed into accessible rails and denser toolbar controls.

**Architecture:** Reuse the current graph page, local SVG renderer, URL state, and panel-collapse helpers. Do not change graph payloads or artifact data; only generated markup, local graph script behavior, CSS layout, tests, and the renderer contract wording change.

**Tech Stack:** Python 3.10, pytest, Playwright, static HTML/CSS/JavaScript generated by `packages/static`.

  - Keep current mobile stacked overrides.

  - Extend the existing graph expand/browser test to assert both side panels collapse/expand and graph state is preserved.

- [ ] **Step 2: Update graph expand script behavior**

In `graph.py`, change `setGraphExpanded()` so button labels and accessible names
track the current state:

```javascript
    if (graphExpand) {
      graphExpand.setAttribute("aria-pressed", nextExpanded ? "true" : "false");
      graphExpand.setAttribute(
        "aria-label",
        nextExpanded ? "Leave graph focus mode" : "Expand graph focus mode"
      );
      graphExpand.textContent = nextExpanded ? "Compact" : "Focus";
    }
```

Then update the `graphExpand` click handler:

```javascript
  if (graphExpand) {
    graphExpand.addEventListener("click", () => {
      const nextExpanded = root.dataset.rayaGraphExpanded !== "true";
      setGraphExpanded(nextExpanded);
      setGraphPanelState("list", !nextExpanded);
      setGraphPanelState("inspector", !nextExpanded);
      render();
    });
  }
```
