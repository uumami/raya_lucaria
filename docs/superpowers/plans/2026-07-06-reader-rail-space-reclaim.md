# Reader Rail Space Reclaim Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reclaim article space when reader rails collapse and make the expanded course map readable.

**Architecture:** Keep the current Glintstone static renderer. Update the foundation contract, add failing shell/layout assertions, then adjust generated markup/CSS/JS so collapsed rails leave the grid and expanded map content comes before secondary tools.

**Tech Stack:** Python 3.10, `uv`, pytest, Playwright e2e tests, static HTML/CSS/JS generated by `packages/static`.

---

## File Map

- Modify `docs/foundation/20_learning_renderer_contract.md`: accept minimal desktop edge openers for collapsed rails instead of a reserved compact map rail.
- Modify `packages/static/src/raya_static/builder.py`: reorder expanded course-map markup so map controls and list come before secondary tools/workspaces.
- Modify `packages/static/src/raya_static/rendering.py`: change desktop collapsed grid templates to remove collapsed columns, style fixed edge openers, compact the expanded tool/workspace areas, and prevent visible truncated labels.
- Modify `packages/static/src/raya_static/shell.py`: when desktop map collapses, hide/inert full map descendants except the visible opener; preserve right-rail inertness.
- Modify `tests/contracts/test_static_builder.py`: assert foundation text and rendered shell expectations.
- Modify `tests/e2e/test_preview_static_read_path.py`: add/adjust browser assertions for article width growth, edge opener geometry, and hidden collapsed descendants.
