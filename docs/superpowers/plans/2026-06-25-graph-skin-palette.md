# Graph Skin Palette Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let validated course skins control graph group colors while preserving static renderer constraints.

**Architecture:** Extend the existing skin parser with one optional token group, `tokens.graph`, and emit those tokens as graph CSS variables inside each skin selector. Keep graph rendering unchanged except for tests and fixture data, because graph chips, SVG nodes, edges, and markers already consume `--raya-graph-group-*` variables.

**Tech Stack:** Python 3.10, PyYAML, pytest, static HTML/CSS/JS generated by `packages/static`.

**Status: implemented.** This checklist is a historical execution record. Current
source support lives in `packages/static/src/raya_static/skins.py`, fixture skin
profiles under `examples/courses/render-fixture/skins/`, role docs, and
contract tests in `tests/contracts/test_static_builder.py`.
