> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Harden the current reader shell so course-map filtering, workspace shortcuts, and shell interaction tests match the learning renderer contract.

**Architecture:** Keep the current static builder and local shell script. Change only generated shortcut href scope and course-map filter match text, then add focused contract and Playwright evidence around existing non-persistent shell behavior.

**Tech Stack:** Python 3.10, pytest, Playwright, static HTML/CSS/JS generated by `packages/static`.
