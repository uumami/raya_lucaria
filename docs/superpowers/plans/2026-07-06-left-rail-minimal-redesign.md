# Left Rail Minimal Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the crowded reader left rail with a compact course-map-first rail that reclaims reading space when collapsed, removes duplicate workspace surfaces, supports deep nested hierarchy, and restores branch expansion within the same browser tab.

**Architecture:** Keep the static renderer architecture: Python emits stable HTML, `shell.js` owns local UI behavior, and `rich.css` owns responsive layout. The left rail becomes one navigation surface with one compact Course Tools area, a filter, and a scrollable map tree; per-branch collapsed state is stored as course-scoped `sessionStorage` UI orientation, not learner progress.

**Tech Stack:** Python 3.10, static HTML/CSS/JavaScript generated by `packages/static`, pytest, Playwright/Chromium e2e tests, foundation and role Markdown docs.

Add:

```javascript
  function courseMapBranchStorageKey() {
    const explicitKey = map.getAttribute("data-raya-course-map-storage-key") || "";
    return explicitKey || "raya:course-map:" + window.location.pathname.split("/").slice(0, -1).join("/");
  }

  function loadStoredCollapsedMapBranches() {
    try {
      const raw = window.sessionStorage.getItem(courseMapBranchStorageKey());
      const parsed = raw ? JSON.parse(raw) : [];
      return Array.isArray(parsed)
        ? new Set(parsed.filter((value) => typeof value === "string" && value))
        : new Set();
    } catch (_error) {
      return new Set();
    }
  }

  function saveCollapsedMapBranches() {
    const collapsed = mapNodeToggles
      .map((button) => button.closest("[data-raya-map-node]"))
      .filter((node) => node && node.dataset.rayaMapExpanded !== "true")
      .map((node) => node.getAttribute("data-raya-map-node") || "")
      .filter(Boolean);
    try {
      window.sessionStorage.setItem(
        courseMapBranchStorageKey(),
        JSON.stringify(collapsed)
      );
    } catch (_error) {
      return;
    }
  }
```
