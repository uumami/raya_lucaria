# raya-schema

Portable contracts and Python validation helpers for the reset baseline.

This package owns:

- `raya.yaml` schema,
- artifact manifest schema,
- page, quanta, links, navigation, index, official object, reference, runtime, execution-plan, cache, and execution-results schemas,
- source course validators,
- artifact validators.

It supports Glintstone and future domains without making renderer choices canonical.
