# OpenDyslexic Font Asset

`OpenDyslexic-Regular.woff` is copied from the Debian `fonts-opendyslexic`
package version `20160623-4`.

Upstream: `http://opendyslexic.org/`

The Debian package records OpenDyslexic as copyright 2012-2016 Abelardo
Gonzalez, based on Bitstream Vera copyright 2003 Bitstream, Inc., under
CC-BY-3.0 and the Bitstream Vera license.

This repository uses the font only as a local static accessibility asset for
generated course pages. Runtime pages must not load OpenDyslexic from a CDN or
external font provider.
