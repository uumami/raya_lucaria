# Packages

Plain package names are the repository default. Raya Lucaria domain names remain the conceptual language.

| Package | Domain |
| --- | --- |
| `cli` | operational command surface |
| `schema` | contracts for all domains |
| `static` | Glintstone |
| `graph` | Primeval Current |
| `identity` | Glintstone Key |
| `study` | Rennala |
| `live` | Debate Parlor |
| `agents` | Sellen |
| `collaboration` | Graven School |

The reset baseline implements `cli`, `schema`, and the first `static` builder.
